# BiciPark My Bike

Mòdul local de bicicletes. Desa marca/model, modalitat, rodes, configuració de pressió habitual, quilometratge i punts de manteniment. Assigna un BiciPark ID local i permet exportar un passaport JSON amb un subconjunt de dades.

Clau: `bicipark.myBike.v1`.

Privacitat v1: no hi ha backend, compte ni registre públic. Només es desa un recordatori opcional dels últims 4 caràcters del número de sèrie; no es publiquen factures, contacte ni identificadors complets.

La pantalla no calcula encara una pressió recomanada ni intervals automàtics de manteniment: aquests dos resultats requereixen regles validades i dades de fabricant abans de presentar-los com a consell.
