# Arrossega el lloc · MVP

MVP inicial del joc geogràfic de Bicipark.

Inclou:
- Barcelona, París i Roma.
- 15 objectius turístics.
- Icones SVG pròpies i lleugeres.
- Clic del jugador.
- Marcador de la ubicació real.
- Línia entre el clic i el punt correcte.
- Càlcul de distància.
- Puntuació per ronda.
- Partides de 5 rondes.
- Selector de ciutat.

## Executar

Des de `C:\projectes\bicipark`:

```powershell
python -m http.server 8000
```

Obrir:

`http://localhost:8000/drag-map-game/`
